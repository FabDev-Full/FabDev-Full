## 🌟 Proyecto Destacado

### 🐾 [PetGuardian](https://www.petguardian.cl) — Plataforma de Cuidado y Seguridad de Mascotas
> **Tecnologías:** Next.js (PWA) + .NET 8 Web API + PostgreSQL (Supabase) + Firebase Push + Brevo API

Plataforma SaaS integral de bienestar animal con **Notificaciones Push en tiempo real**, Carnet Digital con vacunas y desparasitación automatizada, y **Sistema de Emergencias por Placa QR Anti-Estafas** con reporte de geolocalización GPS en vivo.
