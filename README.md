## 🌟 Proyecto Destacado

### 🐾 [PetGuardian.cl](https://www.petguardian.cl) — Plataforma Inteligente de Cuidado y Seguridad de Mascotas

Plataforma SaaS integral de bienestar animal con arquitectura desacoplada de alto rendimiento:

- 🚨 **Sistema de Emergencias por Placa QR Anti-Estafas:** Reporte de geolocalización GPS en vivo con privacidad protegida del dueño.
- 🔔 **Notificaciones Push en Tiempo Real:** Motor de alertas para controles médicos (15 min antes), diario y recordatorios.
- 🩺 **Carnet Digital & Salud Preventiva:** Vacunas anuales y calendario automático de desparasitaciones (3 meses).

> **Arquitectura:** Next.js (PWA) + .NET 8 Web API + PostgreSQL (Supabase) + Firebase Push + Brevo API
